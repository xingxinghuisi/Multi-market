# v0.19 – MIRAO 移动端 PWA

This release brings the existing market, alert, news, and Telegram services into a mobile-first PWA with personal accounts. It builds on the existing `app/` backend and keeps the older desktop workspace available at `/legacy`.
本版本基于现有 `app/` 后端，将行情、提醒、新闻与 Telegram 功能整合进移动优先的 PWA，并加入个人账户。旧版桌面工作台仍可通过 `/legacy` 使用。

## Mobile Experience / 移动端体验

- Added a responsive market overview, watchlist, asset details, asset search and addition, alert management, notification center, news, settings, and profile.
  新增响应式市场总览、关注列表、资产详情、资产搜索与添加、提醒管理、通知中心、新闻、设置和个人中心。
- Added a translucent glass navigation bar, light/dark/system appearance, motion and page transitions, iPhone safe-area support, and reduced-motion/transparency fallbacks.
  新增透明玻璃风格导航、浅色／夜间／跟随系统外观、动效与页面过渡、iPhone 安全区适配，并兼容减少动态效果和透明度设置。
- Added an installable PWA manifest and service worker. Only public pages and static assets are cached; private API responses and market data are never stored in the offline cache.
  新增可安装的 PWA 清单与 Service Worker；离线缓存仅包含公开页面和静态资源，不缓存私人接口响应或行情数据。

## Accounts and Watchlists / 账户与关注

- Added open registration, separate login, logout, and account-scoped watchlists, alerts, notifications, and profile data. Sessions use secure, HttpOnly cookies and CSRF protection.
  新增开放注册、独立登录、退出，以及按账户隔离的关注、提醒、通知和个人资料；会话使用安全的 HttpOnly Cookie 与 CSRF 防护。
- Assets can be added to or removed from a personal watchlist without deleting shared market assets or affecting other users.
  可在个人关注列表中添加或移除资产，不会删除共享行情资产，也不会影响其他用户。
- Existing `default` account data can be claimed through a separate interactive maintenance script after a database backup; it is not assigned to new registrants automatically.
  备份数据库后，可通过独立的交互式维护脚本领取旧 `default` 账户数据；新注册用户不会自动获得旧数据。

## Market Data and Alerts / 行情与提醒

- Reused the existing Binance Spot/Futures and stock data paths. Futures details show available Binance mark price, index price, funding, next funding time, and open interest; missing upstream data is shown as unavailable.
  复用现有 Binance 现货／合约和股票数据链路；合约详情展示可获取的标记价格、指数价格、资金费率、下次结算时间和未平仓量，上游数据缺失时明确显示不可用。
- Added real historical candlesticks where OHLC data exists, and refreshes quotes when the app returns to the foreground without replaying the whole page animation.
  有真实 OHLC 数据时显示历史 K 线；应用回到前台时刷新报价，不重复播放整页入场动画。
- Improved step-alert previews: the first Telegram line now includes the symbol, direction, and current price. Alert numbers shown to a user are consecutive within that user's list; database IDs remain unchanged.
  优化步进提醒预览：Telegram 首行包含资产代码、上涨或下跌方向与当前价格；面向用户展示的提醒编号在其个人列表内连续，数据库 ID 不变。
- Added per-user Telegram Chat ID verification and test messages. New accounts without a bound target retain in-app notifications without sending to the legacy global target.
  新增个人 Telegram Chat ID 验证绑定与测试消息；新账户未绑定接收目标时保留站内通知，不会发送到旧的全局目标。

## Deployment and Verification / 部署与验证

- Added Docker/PWA deployment guidance, a deployment preflight check, and account, mobile API, and service-worker tests. Production secrets, databases, virtual environments, and runtime files are excluded from the repository.
  新增 Docker／PWA 部署指南、部署前检查，以及账户、移动接口和 Service Worker 测试；生产密钥、数据库、虚拟环境与运行时文件不纳入仓库。
- JavaScript tests and syntax checks, plus Python syntax compilation, pass for this release. Full Python tests require installing the project's Python dependencies.
  本版本的 JavaScript 测试、语法检查及 Python 语法编译通过；完整 Python 测试需要安装项目依赖后运行。

Password recovery, iOS Web Push, and iPhone device verification remain future work. This release is a PWA; it is not an App Store build.
密码找回、iOS Web Push 和 iPhone 真机验证仍是后续工作。本版本为 PWA，尚非 App Store 安装包。
